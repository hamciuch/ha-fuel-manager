# Fuel Manager (Tankowania)

Dziennik tankowań w Home Assistant: ręczne wpisywanie (przebieg, litry,
cena/litr, kwota), automatyczny czas i lokalizacja, wyszukiwanie najbliższej
stacji (OpenStreetMap + historia), wybór rodzaju paliwa i **import z Fuelio**.

Po instalacji dodaj integrację przez **Ustawienia → Urządzenia i usługi →
Dodaj integrację → Fuel Manager** i podaj nazwę pojazdu.

Pełna dokumentacja, przykładowy formularz i dashboard – w README repozytorium.
